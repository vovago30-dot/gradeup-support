Політика конфіденційності

Останнє оновлення: 31 серпня 2026 р.

GradeUp — освітній застосунок для школярів, вчителів та директорів шкіл, що працює за програмою НУШ. Ця політика пояснює, які дані ми збираємо, як їх використовуємо та як захищаємо.

Які дані ми збираємо

  • Обліковий запис: електронна пошта та пароль (зберігається у зашифрованому вигляді) для входу в застосунок.
  • Навчальні дані: результати тестів, прогрес, рівні, зароблені монети та досягнення в межах гейміфікованої системи.
  • Дані профілю вчителя/директора: ім'я, школа, клас, дані про учнів у межах керування навчальним процесом.
  • Технічні дані: тип пристрою, версія ОС, дані про збої застосунку (діагностика) — для покращення стабільності роботи.
  • Дані підписки: статус активної підписки GradeUp Pro обробляється через RevenueCat та App Store/Google Play; ми не бачимо і не зберігаємо дані банківської картки.

Захист даних учнів

Реальні імена учнів ніколи не передаються на наші сервери. Замість імені використовується анонімний ідентифікатор (акронім), який генерується локально на пристрої вчителя. Це зроблено навмисно, щоб мінімізувати обробку персональних даних неповнолітніх.

Як ми використовуємо дані

  • Для функціонування застосунку: авторизація, збереження прогресу, синхронізація між пристроями.
  • Для гейміфікації: нарахування монет, рівнів, досягнень.
  • Для AI-функцій (пояснення тем, генерація навчального контенту) — запити обробляються через сторонній AI-сервіс без прив'язки до реального імені учня.
  • Для сповіщень: push-повідомлення про нові завдання, результати, нагадування.
  • Для покращення застосунку: анонімна діагностика збоїв.

Ми не продаємо ваші дані

GradeUp не продає персональні дані третім сторонам і не використовує їх для рекламного таргетингу.

Сторонні сервіси

Для роботи застосунку ми використовуємо такі сторонні сервіси, кожен з яких має власну політику конфіденційності:

  • Supabase — зберігання даних та автентифікація.
  • Firebase (Google) — push-сповіщення.
  • RevenueCat — обробка підписок GradeUp Pro.

Діти та навчальні заклади

GradeUp призначений для використання учнями 5–11 класів під наглядом вчителів та шкіл. Школи та вчителі, що реєструють учнів у системі, відповідають за отримання необхідних дозволів згідно з чинним законодавством про освіту.
